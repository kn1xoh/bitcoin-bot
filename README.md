# BTC мониторинг

Telegram-бот, который каждые ~5 минут смотрит на рынок BTC (Coinbase, запасной источник — Kraken;
индекс страха и жадности — alternative.me) и пишет, когда происходит что-то важное.
Работает бесплатно на GitHub Actions, компьютер включённым держать не нужно.

## Что присылает бот

| Сигнал | Когда |
|---|---|
| Резкое движение | цена изменилась на 3% и больше за 30 минут (пауза между одинаковыми — 30 минут) |
| Медленное движение | −/+5% за 24 часа, −/+10% за 7 дней |
| Пробой уровня | цена пересекла один из твоих уровней (с запасом 0,3%, чтобы не дёргалось) |
| Просадка | цена на 15 / 20 / 30% ниже максимума за 90 дней — по одному сообщению на ступень |
| 200-дневная средняя | цена ушла ниже средней или вернулась выше (с запасом 1%) |
| RSI | дневной RSI(14) упал ниже 30 и потом поднялся выше 35 |
| Страх и жадность | вход в «Страх» / «Сильный страх», выход из страха |
| Длительность страха | страх держится 3, 7, 14, 30 дней подряд |
| Сводка | раз в день после 9:00 по Москве: цена, изменения, просадка, средняя, RSI, индекс, ближайшие уровни |

Если за один запуск сработало несколько сигналов, они приходят одним сообщением.

Сообщения оформлены HTML-разметкой Telegram: жирный заголовок, значения в моноширинном блоке
с выравниванием, направление цены — ▲ / ▼. Если Telegram вдруг не примет разметку, бот отправит то же
сообщение простым текстом.

## Команды в Telegram

- `/price` — сводка прямо сейчас
- `/levels` — список уровней
- `/add 60000 65k` — добавить уровни (можно `60 000`, `65k`, через пробел или запятую)
- `/del 60000` — удалить уровень, `/del all` — удалить все
- `/help` — справка

Бот не работает постоянно: команды он забирает при каждом запуске, поэтому ответ приходит
через 5–15 минут. Команды принимаются только из чата `TELEGRAM_CHAT_ID`, сообщения старше часа игнорируются.

## Запуск

### 1. Узнать свой chat_id
1. Напиши своему боту в Telegram любое сообщение (например, `/start`).
2. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив токен.
3. Найди `"chat":{"id":123456789` — это число и есть chat_id.

### 2. Репозиторий на GitHub
Публичный репозиторий (в нём минуты Actions бесплатны без лимита). Токен никто не увидит — он в секретах.

### 3. Секреты
Settings → Secrets and variables → Actions → New repository secret:
- `TELEGRAM_BOT_TOKEN` — токен бота
- `TELEGRAM_CHAT_ID` — chat_id из шага 1

### 4. Проверить
Actions → BTC monitor → Run workflow → отметить «Отправить тестовое сообщение» → Run.
Придёт сводка с текущими показателями.

## Настройки
Все пороги — в `.github/workflows/monitor.yml`, блок `env`:

- `THRESHOLD_PCT`, `WINDOW_MIN`, `COOLDOWN_MIN` — резкие движения
- `SLOW_RULES` — медленные движения в формате `часы:процент`, например `24:5,168:10`
- `LEVELS` — начальные уровни. Используются только при первом запуске; дальше список живёт в `state.json`
  и меняется командами `/add` и `/del`
- `LEVEL_BUFFER_PCT` — запас при пробое уровня, %
- `DRAWDOWN_DAYS`, `DRAWDOWN_STEPS` — период максимума и ступени просадки
- `TECH_ALERTS`, `RSI_LOW`, `RSI_EXIT` — сигналы по средней и RSI
- `FNG_ALERTS`, `FEAR_STREAK_DAYS` — индекс страха и жадности
- `SUMMARY_HOUR`, `TZ_OFFSET` — час сводки и часовой пояс (смещение от UTC)
- `COMMANDS` — `false`, чтобы отключить команды

## Как это устроено
- `state.json` хранит состояние: уровни, время последних уведомлений, текущие зоны, дату сводки, номер
  последнего прочитанного сообщения Telegram. Бот сам коммитит его в репозиторий, когда оно меняется.
- При первом запуске бот запоминает текущее положение (выше/ниже уровней, средней и т. д.) и не шлёт
  по нему уведомлений — сигналы приходят только при изменениях.
- Ежедневная сводка меняет `state.json` каждый день, поэтому GitHub не отключит расписание
  из-за 60 дней без активности.

## Ограничения
- GitHub не гарантирует точное время запуска по расписанию: запуски могут опаздывать на 5–20 минут,
  иногда пропускаться. Поэтому окно резкого движения — 30 минут, а медленные движения ловятся отдельно.
- Индекс страха и жадности обновляется раз в сутки (около 03:00 по Москве).
- 200-дневная средняя и RSI считаются по дневным свечам с учётом текущего незакрытого дня,
  поэтому внутри дня значения немного плавают.
- Это сигналы для внимания, а не торговые рекомендации.
