# BTC мониторинг

Каждые ~5 минут проверяет цену BTC (Coinbase, запасной источник — Kraken) и пишет в Telegram,
если за последние 15 минут цена упала или выросла на 3% и больше.
Между одинаковыми уведомлениями — пауза 30 минут.

Работает бесплатно на GitHub Actions, компьютер включённым держать не нужно.

## Запуск

### 1. Узнать свой chat_id
1. Напиши своему боту в Telegram любое сообщение (например, `/start`).
2. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив токен.
3. Найди `"chat":{"id":123456789` — это число и есть chat_id.

### 2. Создать репозиторий на GitHub
1. Зарегистрируйся на github.com, если ещё нет аккаунта.
2. Создай **публичный** репозиторий (New repository). В публичных репозиториях минуты Actions бесплатны без лимита;
   в приватном бесплатных 2000 минут в месяц не хватит на проверку каждые 5 минут.
   Токен при этом никто не увидит — он хранится в секретах, а не в коде.
3. Загрузи файлы проекта (Add file → Upload files). Папку `.github/workflows` проще создать вручную:
   Add file → Create new file, имя `.github/workflows/monitor.yml`, вставить содержимое файла.

### 3. Добавить секреты
Settings → Secrets and variables → Actions → New repository secret:
- `TELEGRAM_BOT_TOKEN` — токен бота
- `TELEGRAM_CHAT_ID` — chat_id из шага 1

### 4. Проверить
Actions → BTC monitor → Run workflow → отметить «Отправить тестовое сообщение» → Run.
Через минуту в Telegram придёт сообщение с текущей ценой. Дальше проверки идут сами по расписанию.

## Настройки
Порог, окно и паузу меняют в `.github/workflows/monitor.yml`:
`THRESHOLD_PCT` (%), `WINDOW_MIN` (минуты), `COOLDOWN_MIN` (минуты).

## Ограничения
- GitHub не гарантирует точное время запуска по расписанию: запуски могут опаздывать на несколько минут,
  иногда пропускаться в часы высокой нагрузки.
- В публичных репозиториях GitHub отключает расписание, если в репозитории 60 дней не было активности.
  Придёт письмо — достаточно нажать Enable workflow во вкладке Actions.
- `state.json` хранит время последних уведомлений; бот сам коммитит его в репозиторий.
